# my-first-project
my first gihub project
Create a cheerful nursery rhyme song for children aged 2–5 years.

**Music style:** Happy, playful, gentle children's music with a catchy melody, ukulele, piano, bells, xylophone, hand claps, and soft percussion.

**Vocals:** Sweet, clear, friendly female singing voice with simple English pronunciation. Add a small children's choir for the chorus.

**Tempo:** 100–120 BPM, bouncy rhythm, easy for toddlers to sing along.

**Structure:**
1. Short musical introduction (5 seconds).
2. First verse.
3. Catchy chorus.
4. Second verse.
5. Repeat the chorus.
6. Gentle musical ending.

Keep the melody memorable, the lyrics easy to understand, and the sound pleasant for young children. Generate complete vocals and instrumental music with no spoken instructions or background noise.

Use original lyrics and an original melody.
